## 实体类生成计划

根据数据库表结构，将创建以下 5 个实体类：

### 1. Code.java - g_code 表
- CODE_ID (int): 编码 ID
- TYPE (String): 编码类型
- TYPE_NAME (String): 类型名称
- CODE_DESC (String): 编码描述
- NUM (int): 数值
- STATUS (String): 状态

### 2. User.java - g_user 表
- USER_ID (Long): 用户 ID
- USER_NAME (String): 用户名
- PASSWORD (String): BCrypt 加密密码
- NAME (String): 姓名
- USER_STATUS (Integer): 用户状态
- ROLE (Integer): 用户身份
- LOGIN_FAIL_COUNT (Integer): 登录失败次数
- LOCK_TIME (Date): 账号锁定时间

### 3. Student.java - zw_student 表
- STUDENT_ID (Long): 学生 ID
- USER_ID (Long): 关联用户 ID
- SEX (Integer): 性别
- STUDENT_CODE (Integer): 学号
- EMAIL (String): 邮箱
- STUDENT_STATUS (Integer): 学生状态
- STUDENT_TYPE (Integer): 学生类型
- PHONE (Long): 电话
- GRA (Integer): 年级
- CLA (Integer): 班级

### 4. Teacher.java - zw_teacher 表
- TEACHER_ID (Long): 教师 ID
- USER_ID (Long): 关联用户 ID
- SEX (Integer): 性别
- TEACHER_CODE (Integer): 教师编号
- TEACH_SUBJECT (Integer): 教学科目
- TEACHER_STATUS (Integer): 教师状态
- TEACHER_TYPE (Integer): 教师类型
- PHONE (Long): 电话
- GRA (Integer): 年级
- CLA (Integer): 班级

### 代码规范：
- 手动编写 getter/setter 方法
- 不使用 MyBatis-Plus 注解
- 字段名与数据库保持一致
- 添加中文注释说明字段含义
- 存放位置：`ScoreBackend/src/main/java/org/gzw/backend/entity/`
