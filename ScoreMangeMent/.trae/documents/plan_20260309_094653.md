## 实施计划：User、Student、Teacher 增删改查功能

### 一、创建 Mapper 接口（4 个）
1. **UserMapper.java** - 用户数据访问层
2. **StudentMapper.java** - 学生数据访问层
3. **TeacherMapper.java** - 教师数据访问层
4. **CodeMapper.java** - 编码字典数据访问层（用于关联查询）

### 二、创建 Mapper XML 文件（4 个）
1. **UserMapper.xml** - 包含：
   - 基础 CRUD 操作
   - 关联查询 g_code 获取 userStatus 和 role 的实际含义
   
2. **StudentMapper.xml** - 包含：
   - 基础 CRUD 操作
   - 关联查询 g_code 获取 sex、studentStatus、studentType 的实际含义
   
3. **TeacherMapper.xml** - 包含：
   - 基础 CRUD 操作
   - 关联查询 g_code 获取 sex、teacherStatus、teacherType、teachSubject 的实际含义
   
4. **CodeMapper.xml** - 根据 CODE_ID 查询编码信息

### 三、创建实体 VO 类（3 个，用于返回前端展示数据）
1. **UserVO.java** - 包含用户信息及状态、角色的中文描述
2. **StudentVO.java** - 包含学生信息及性别、状态、类型的中文描述
3. **TeacherVO.java** - 包含教师信息及性别、状态、类型、科目的中文描述

### 四、创建 Service 接口和实现类（6 个）
1. UserService.java / UserServiceImpl.java
2. StudentService.java / StudentServiceImpl.java
3. TeacherService.java / TeacherServiceImpl.java

### 五、创建 Controller 控制器（3 个）
1. UserController.java - 用户管理接口
2. StudentController.java - 学生管理接口
3. TeacherController.java - 教师管理接口

### 六、RESTful API 接口设计
每个模块提供以下接口：
- `GET /list` - 分页查询列表（带 VO 转换）
- `GET /{id}` - 根据 ID 查询详情
- `POST /add` - 新增
- `PUT /update` - 修改
- `DELETE /{id}` - 删除
