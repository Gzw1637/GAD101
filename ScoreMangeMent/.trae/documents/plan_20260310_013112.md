## 登录功能实施计划

### 一、创建 DTO 类（2 个）
1. **LoginRequest.java** - 登录请求参数（userName, password）
2. **LoginResponse.java** - 登录响应（userId, userName, name, role, roleDesc, token, redirectPath）

### 二、创建工具类（1 个）
1. **JwtUtil.java** - JWT 工具类，用于生成和解析 Token
   - 生成 Token（包含 userId, role 信息）
   - 解析 Token
   - 验证 Token 有效性

### 三、创建拦截器（2 个）
1. **LoginInterceptor.java** - 登录拦截器
   - 拦截需要登录的请求
   - 验证 Token 有效性
   - 放行登录接口和静态资源

2. **InterceptorConfig.java** - 拦截器配置
   - 配置拦截路径
   - 配置放行路径

### 四、修改 UserMapper 和 XML
1. **UserMapper.java** - 添加根据用户名查询用户的方法
2. **UserMapper.xml** - 实现关联查询，获取角色描述

### 五、创建 LoginService 和实现类
1. **LoginService.java** - 登录服务接口
2. **LoginServiceImpl.java** - 登录服务实现
   - 验证用户名密码
   - 生成 Token
   - 返回用户信息和跳转路径

### 六、创建 LoginController
1. **LoginController.java** - 登录控制器
   - `POST /api/login` - 登录接口
   - `POST /api/logout` - 登出接口
   - `GET /api/userInfo` - 获取当前用户信息

### 七、角色权限映射
- **role = 14981001**（学生）→ 重定向到 `/student` 页面
- **role = 14981002**（教师）→ 重定向到 `/teacher` 页面
- **role = 14981003**（管理员）→ 重定向到 `/admin` 页面
