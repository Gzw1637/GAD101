## 修复方案

### 问题分析
- `UserVO` 用于前端展示，不应该包含 `password` 字段（正确）
- 但登录验证需要密码，当前 `selectByUserName` 返回 `UserVO` 无法获取密码

### 解决方案
1. **修改 UserMapper**：`selectByUserName` 返回 `User` 实体类（包含 password），用于登录验证
2. **修改 UserMapper.xml**：使用 `UserResultMap` 映射到 User 实体
3. **修改 LoginServiceImpl**：使用 User 实体接收查询结果，验证密码后再转换为 LoginResponse

这样设计的好处：
- VO 保持纯净，不包含敏感信息
- 实体类用于内部业务逻辑处理
- 符合分层架构最佳实践
