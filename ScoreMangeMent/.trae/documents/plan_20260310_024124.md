## 修改管理员主页和用户管理

### 问题分析：
1. **AdminDashboard.vue** - 使用的是旧接口（`/student/getAll` 等），应该调用新接口（`/api/student/list` 等）
2. **AdminUser.vue** - 使用的是旧接口（`/user/getAll`），应该调用新接口（`/api/user/list`）
3. **请求方式** - 应该使用封装好的 request 工具，自动携带 token

### 修改方案：

#### 1. AdminDashboard.vue
- 导入 `request` 工具
- 修改学生接口：`/student/getAll` → `/api/student/list`
- 修改教师接口：`/teacher/getAll` → `/api/teacher/list`
- 修改响应数据解析：`response.data.data` → `response.data`

#### 2. AdminUser.vue
- 导入 `request` 工具
- 修改用户列表接口：`/user/getAll` → `/api/user/list`
- 修改添加接口：`/user/create` → `/api/user/add`
- 修改更新接口：`/user/update` → `/api/user/update`
- 修改删除接口：`/user/delete/{id}` → `/api/user/{id}`
- 修改搜索功能（后端暂无搜索接口，先调用 list 后前端过滤）
