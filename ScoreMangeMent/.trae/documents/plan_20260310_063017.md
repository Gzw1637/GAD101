## 修复学生信息展示和表单验证

### 问题分析：
1. **StudentVO 缺少 name 字段** - 无法显示用户姓名
2. **前端使用 name 字段但 VO 中没有** - 导致显示为空
3. **表单验证过于严格** - 很多非必填字段设为必填
4. **学号和年级使用输入框更合适** - 不限制位数

### 修改方案：

#### 后端修改：
1. **StudentVO.java** - 添加 name 字段及其 getter/setter
2. **StudentMapper.xml** - 确保查询时包含 name 字段

#### 前端修改：
1. **AdminStudent.vue** - 调整表单验证规则
   - 只保留用户名、姓名、学号为必填
   - 学号改为普通输入框（不限制位数）
   - 年级改为普通输入框（不限制范围）
   - 其他字段改为选填
