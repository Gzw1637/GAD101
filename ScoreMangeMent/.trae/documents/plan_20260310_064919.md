# 修复学生信息展示和表单验证方案

## 问题分析
1. **StudentVO 已有 name 字段** - 实际上已经包含了 name 字段及其 getter/setter
2. **前端使用 name 字段正常** - AdminStudent.vue 中正确使用了 name 字段
3. **表单验证过于严格** - 当前所有字段几乎都是必填的
4. **学号和年级使用输入框限制了位数** - el-input-number 限制了输入范围

## 修改方案

### 后端修改（已符合预期）
- **StudentVO.java** - 已经包含 name 字段及其 getter/setter（无需修改）
- **StudentMapper.xml** - 查询时已包含 name 字段（无需修改）

### 前端修改
1. **AdminStudent.vue** - 调整表单验证规则
   - 只保留用户名、姓名、学号为必填
   - 学号改为普通输入框（不限制位数）
   - 年级改为普通输入框（不限制范围）
   - 其他字段改为选填
