# 修复学生信息姓名字段显示问题

## 问题分析

从控制台日志可以看到，SQL 查询返回的列名是 `USER_NAME`，但没有看到 `NAME` 字段。问题在于：

1. **StudentMapper.xml 的 SQL 查询** - 查询时使用了 `u.USER_NAME`，但没有查询 `u.NAME` 字段
2. **StudentVO 中虽然有 name 字段**，但 SQL 查询时没有从 g_user 表中获取 NAME 字段

## 修改方案

### 修改 StudentMapper.xml

修改两个查询语句（selectById 和 selectAll），在 SELECT 语句中添加 `u.NAME` 字段：

```xml
<select id="selectById" resultMap="StudentVOResultMap" parameterType="java.lang.Long">
    SELECT s.*, u.USER_NAME, u.NAME,
           sex.CODE_DESC as SEX_DESC,
           ss.CODE_DESC as STUDENT_STATUS_DESC,
           st.CODE_DESC as STUDENT_TYPE_DESC
    FROM zw_student s
    LEFT JOIN g_user u ON s.USER_ID = u.USER_ID
    LEFT JOIN g_code sex ON s.SEX = sex.CODE_ID
    LEFT JOIN g_code ss ON s.STUDENT_STATUS = ss.CODE_ID
    LEFT JOIN g_code st ON s.STUDENT_TYPE = st.CODE_ID
    WHERE s.STUDENT_ID = #{studentId}
</select>
