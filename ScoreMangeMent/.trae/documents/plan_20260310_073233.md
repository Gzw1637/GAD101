## 修复计划

### 问题分析
密码没有经过 BCrypt 加密就直接存入数据库，需要在 Service 层对密码进行加密处理。

### 需要修复的地方

#### 1. StudentServiceImpl.java
- ✅ 已添加 BCryptPasswordEncoder 注入
- ✅ 已在 `addStudent()` 方法中对密码加密
- ⚠️ 需要在 `updateStudent()` 方法中也对密码加密（如果密码被修改）

#### 2. UserServiceImpl.java
- ❌ 需要添加 BCryptPasswordEncoder 注入
- ❌ 需要在 `addUser()` 方法中对密码加密
- ❌ 需要在 `updateUser()` 方法中对密码加密（如果密码被修改）

### 具体修改内容

#### StudentServiceImpl.java
```java
// updateStudent 方法中添加密码加密逻辑
if (student.getPassword() != null && !student.getPassword().isEmpty() 
    && !student.getPassword().equals("********")) {
    student.setPassword(passwordEncoder.encode(student.getPassword()));
}
```

#### UserServiceImpl.java
```java
// 添加注入
@Autowired
private BCryptPasswordEncoder passwordEncoder;

// addUser 方法
if (user.getPassword() != null && !user.getPassword().isEmpty()) {
    user.setPassword(passwordEncoder.encode(user.getPassword()));
}

// updateUser 方法
if (user.getPassword() != null && !user.getPassword().isEmpty() 
    && !user.getPassword().equals("********")) {
    user.setPassword(passwordEncoder.encode(user.getPassword()));
} else {
    user.setPassword(null); // 密码未修改则设为 null，避免覆盖原密码
}
```

### 涉及文件
- `StudentServiceImpl.java` - 修改 updateStudent 方法
- `UserServiceImpl.java` - 添加密码加密逻辑

### 预期效果
所有添加/修改操作都会自动对密码进行 BCrypt 加密后再存入数据库。
