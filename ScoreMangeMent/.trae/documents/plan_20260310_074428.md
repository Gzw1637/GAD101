## 修复计划

### 问题
通过学生管理添加的学生，在用户管理中显示角色和状态不正确。

### 原因分析
在 `StudentMapper.xml` 的 `insertUser` 语句中，设置的默认值错误：
- 当前：`USER_STATUS = 10021001`（教师在职状态），`ROLE = 10041003`（不存在的编码）
- 应该：`USER_STATUS = 10001001`（有效），`ROLE = 14981001`（学生）

### 解决方案

#### 修改 StudentMapper.xml
将 `insertUser` 语句中的默认值修改为正确的编码：
```xml
<insert id="insertUser" parameterType="org.gzw.backend.entity.Student">
    INSERT INTO g_user (USER_ID, USER_NAME, PASSWORD, NAME, USER_STATUS, ROLE, LOGIN_FAIL_COUNT, LOCK_TIME)
    VALUES (#{userId}, #{userName}, #{password}, #{name}, 10001001, 14981001, 0, null)
</insert>
```

### 涉及文件
- `StudentMapper.xml` - 修改 insertUser 语句中的 USER_STATUS 和 ROLE 默认值

### 预期效果
通过学生管理添加的学生，在用户管理中查看时：
- 角色显示为"学生"（14981001）
- 状态显示为"有效"（10001001）
