## 修改计划

### 需求说明

1. **用户管理（AdminUser.vue）**
   - 编辑用户时，锁定"角色"字段不允许修改
   - **注意**：之前已经添加了 `:disabled="dialogType === 'edit'"`，但由于移除了 `dialogType` 变量，需要改为始终禁用

2. **学生管理（AdminStudent.vue）**
   - 添加/修改学生时，对手机号进行验证
   - 不符合规定的手机号不允许保存
   - 手机号验证规则：11 位数字，以 1 开头

### 具体修改内容

#### 1. AdminUser.vue - 锁定角色字段

由于之前移除了 `dialogType` 变量，需要将角色的禁用条件改为始终禁用：

```vue
<el-form-item label="角色" prop="role">
  <el-select v-model="formData.role" placeholder="请选择角色" disabled>
    <el-option label="学生" value="14981001" />
    <el-option label="教师" value="14981002" />
    <el-option label="管理员" value="14981003" />
  </el-select>
</el-form-item>
```

#### 2. AdminStudent.vue - 添加手机号验证

**添加表单验证规则：**
```javascript
const rules = {
  userName: [
    { required: true, message: '请输入用户名', trigger: 'blur' }
  ],
  name: [
    { required: true, message: '请输入姓名', trigger: 'blur' }
  ],
  studentCode: [
    { required: true, message: '请输入学号', trigger: 'blur' }
  ],
  phone: [
    { 
      pattern: /^1[3-9]\d{9}$/, 
      message: '请输入正确的手机号码', 
      trigger: 'blur' 
    }
  ]
}
```

**修改电话输入框，添加验证：**
```vue
<el-form-item label="电话" prop="phone">
  <el-input v-model="formData.phone" placeholder="请输入电话" />
</el-form-item>
```

### 涉及文件
- `AdminUser.vue` - 修改角色字段为始终禁用
- `AdminStudent.vue` - 添加手机号验证规则和验证提示

### 预期效果
- **用户管理**：编辑用户时，角色字段始终为灰色不可修改状态
- **学生管理**：添加或修改学生时，如果手机号格式不正确，会提示"请输入正确的手机号码"且无法保存
- **手机号验证规则**：11 位数字，以 1 开头，第二位为 3-9（符合中国移动手机号规则）
