## 创建 AdminTeacher.vue 教师管理页面

### 一、后端修改

#### 1. **修改 Teacher 实体类**
- 添加 `userName` 和 `password` 字段（用于添加/编辑时传递用户信息）

#### 2. **修改 TeacherMapper 接口**
- 添加 `insertUser(Teacher teacher)` 方法
- 添加 `updateUser(Teacher teacher)` 方法
- 添加 `deleteUserByUserId(Long userId)` 方法

#### 3. **修改 TeacherMapper.xml**
- 添加 `insertUser` SQL：向 g_user 表插入用户
- 添加 `updateUser` SQL：更新 g_user 表用户信息
- 添加 `deleteUserByUserId` SQL：删除 g_user 表用户
- 修改 `selectAll` 的 ORDER BY 为 `u.USER_NAME`（按用户名排序）

#### 4. **修改 TeacherServiceImpl**
仿照 StudentServiceImpl 实现：
- `addTeacher`：生成 userId，加密密码，先插入用户表，再插入教师表
- `updateTeacher`：处理密码加密，更新用户表和教师表
- `deleteTeacher`：先删除教师表，再删除用户表
- 使用 `@Transactional` 注解保证事务一致性

### 二、前端实现

#### 创建 AdminTeacher.vue 页面
仿照 AdminStudent.vue 实现：
- **表格展示**：显示用户名、姓名、性别、教师编号、教学科目、状态、类型、电话、年级、班级、操作
- **搜索功能**：按姓名搜索
- **分页功能**：每页 10/20/50/100 条
- **添加对话框**：表单包含用户名、姓名、密码、性别、教师编号、教学科目、状态、类型、电话、年级、班级
- **编辑对话框**：密码显示为占位符 `********`
- **删除确认**：ElMessageBox 二次确认
- **数据字典映射**：
  - 性别：10031001=男，10031002=女
  - 教师状态：10011001=在职，10011002=离职，10011003=退休等
  - 教师类型：11011001=普通教师，11011002=骨干教师，11011003=学科带头人等
  - 教学科目：从代码表获取

### 三、预期效果
- 管理员可以在 AdminTeacher.vue 页面查看、添加、编辑、删除教师信息
- 添加教师时自动同步创建用户账号
- 修改教师信息时同步更新用户表
- 删除教师时同步删除用户账号
- 教师列表按用户名排序展示
