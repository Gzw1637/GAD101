## 实现用户解封功能

### 功能说明
在用户管理页面的操作列中，添加"解封"按钮（在编辑按钮右侧），当用户账号被锁定（lockTime 不为空且 loginFailCount >= 5）时显示，点击后重置用户的登录失败次数和锁定时间。

### 实现方案

#### 一、后端修改

**1. UserService.java**
- 添加 `unlockUser(Long userId)` 方法接口

**2. UserServiceImpl.java**
- 实现 `unlockUser` 方法：重置 loginFailCount = 0, lockTime = null

**3. UserController.java**
- 添加 `PUT /api/user/unlock/{userId}` 接口

**4. UserMapper.java**
- 添加 `unlockUser(Long userId)` 方法

**5. UserMapper.xml**
- 添加 `unlockUser` SQL 语句

#### 二、前端修改

**AdminUser.vue**
1. **表格列修改**：
   - 在操作列添加"解封"按钮（在编辑按钮右侧）
   - 只有当用户被锁定时才显示解封按钮（loginFailCount >= 5 或 lockTime 不为空）

2. **添加解封方法**：
   - `handleUnlockUser(user)`：调用后端接口解封用户
   - 使用 ElMessageBox 确认操作
   - 解封成功后刷新列表

3. **显示锁定状态**：
   - 可以在状态列或新增列显示锁定信息（可选）

### 预期效果
- 管理员可以在用户管理页面看到被锁定的用户
- 点击"解封"按钮后确认操作
- 解封成功后用户可以重新登录
