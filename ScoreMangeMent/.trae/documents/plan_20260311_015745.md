## 计划：创建考试管理模块

### 1. Mapper 层
**文件**: `ExamMapper.java`
- 位置：`ScoreBackend/src/main/java/org/gzw/backend/mapper/ExamMapper.java`
- 方法：
  - `insert(Exam exam)` - 插入考试记录
  - `update(Exam exam)` - 更新考试记录
  - `deleteById(Long examId)` - 根据 ID 删除
  - `selectById(Long examId)` - 根据 ID 查询
  - `selectAll()` - 查询所有考试

**文件**: `ExamMapper.xml`
- 位置：`ScoreBackend/src/main/resources/mapper/ExamMapper.xml`
- 配置 ResultMap 映射
- 编写 CRUD SQL 语句

### 2. Service 层
**接口**: `ExamService.java`
- 位置：`ScoreBackend/src/main/java/org/gzw/backend/service/ExamService.java`
- 方法：
  - `addExam(Exam exam)` - 添加考试
  - `updateExam(Exam exam)` - 更新考试
  - `deleteExam(Long examId)` - 删除考试
  - `getExamById(Long examId)` - 根据 ID 查询
  - `getAllExams()` - 查询所有考试

**实现类**: `ExamServiceImpl.java`
- 位置：`ScoreBackend/src/main/java/org/gzw/backend/service/Impl/ExamServiceImpl.java`
- 实现业务逻辑，添加事务控制

### 3. Controller 层
**文件**: `ExamController.java`
- 位置：`ScoreBackend/src/main/java/org/gzw/backend/controller/ExamController.java`
- RESTful API 接口：
  - `POST /api/exam/add` - 添加考试
  - `PUT /api/exam/update` - 更新考试
  - `DELETE /api/exam/delete/{examId}` - 删除考试
  - `GET /api/exam/getById/{examId}` - 查询单个考试
  - `GET /api/exam/list` - 查询所有考试

### 4. 代码规范
- 遵循现有代码风格（参考 Student 模块）
- 使用 MyBatis 编写 mapper.xml
- 手动编写 getter/setter（已符合）
- 使用 `@Transactional` 事务注解
- 统一返回 `Result` 结果封装
