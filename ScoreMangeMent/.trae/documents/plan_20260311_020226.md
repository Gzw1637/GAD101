## 计划：创建考试管理页面

### 1. 创建 ExamVO 类
**位置**: `ScoreBackend/src/main/java/org/gzw/backend/entity/vo/ExamVO.java`
- 包含字段：
  - `examCode` (Long) - 考试代码
  - `examName` (String) - 考试名称
  - `subjectType` (Integer) - 科目类型
  - `subjectTypeDesc` (String) - 科目类型描述
  - `examLv` (Integer) - 考试级别
  - `examLvDesc` (String) - 考试级别描述
  - `examTime` (Date) - 考试时间
  - `userName` (String) - 用户名（来自 user 表）
  - `name` (String) - 姓名（来自 user 表）
- 不包含 `examId` 和 `userId` 字段
- 手动编写 getter/setter 方法

### 2. 修改 ExamMapper 和 ExamMapper.xml
- 修改 `selectById` 和 `selectAll` 返回 `ExamVO` 类型
- 更新 SQL 查询以关联 g_user 表获取用户名和姓名

### 3. 修改 ExamService 和 ExamServiceImpl
- 更新返回类型为 `ExamVO`
