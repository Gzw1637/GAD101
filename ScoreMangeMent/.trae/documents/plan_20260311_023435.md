## 问题分析

### 问题原因
1. `ExamVO` 类中**缺少 `examId` 和 `userId` 字段**
2. 前端编辑时尝试访问 `exam.examId` 和 `exam.userId`，但这两个字段在 `ExamVO` 中不存在
3. 导致更新操作时无法正确传递考试 ID，更新失败

### 解决方案

**在 `ExamVO` 类中添加 `examId` 和 `userId` 字段**

虽然表格展示时不需要显示这两个字段，但在编辑和更新操作时需要使用它们，所以必须在 VO 类中包含这些字段。

### 修改文件
- `ScoreBackend/src/main/java/org/gzw/backend/entity/vo/ExamVO.java`

### 添加的字段
```java
private Long examId;      // 考试 ID（用于更新操作）
private Long userId;      // 用户 ID（用于更新操作）
```

### 同时修改 Mapper.xml
在 SQL 查询中添加 `EXAM_ID` 和 `USER_ID` 列的查询，确保 VO 对象能获取到这些值。
