## 问题分析

### 问题
当前所有学科组长都出现在负责人选择框中，没有根据考试科科目进行过滤。李星云是物理老师（`teachSubject=10111004`），不应该出现在数学考试（`subjectType=10111002`）的负责人选项中。

### 解决方案

**前端动态过滤负责人列表**：
1. 加载所有学科组长到内存中
2. 当用户选择科目类型时，根据 `subjectType` 过滤负责人列表
3. 只显示 `teachSubject === subjectType` 的学科组长

### 修改文件
- `ScoreFrontend/src/views/AdminExam.vue`
  - 修改 `loadUserList()` 加载所有学科组长
  - 添加 `filteredUserList` 计算属性用于显示
  - 添加 `handleSubjectTypeChange` 方法监听科目变化
  - 在 `handleEditExam` 中根据科目过滤负责人

### 实现逻辑
```javascript
// 原始学科组长列表（包含所有）
const allSubjectLeaders = ref([])

// 过滤后的负责人列表（根据科目类型）
const filteredUserList = computed(() => {
  if (!formData.subjectType) return allSubjectLeaders.value
  return allSubjectLeaders.value.filter(
    teacher => teacher.teachSubject === Number(formData.subjectType)
  )
})
```
