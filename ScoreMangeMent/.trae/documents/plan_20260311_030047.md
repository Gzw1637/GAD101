## 计划：添加 GRA（年级）字段到考试管理模块

### 问题分析
数据库表 `g_exam` 已添加 `GRA` 字段，需要在以下位置同步更新：
1. 实体类（Exam、ExamVO）
2. Mapper XML 配置
3. 前端页面（AdminExam.vue）
4. 负责人过滤逻辑（增加年级匹配）

### 修改方案

#### 1. 后端实体类
**文件**: `Exam.java`
- 添加 `gra` 字段（Integer 类型）
- 添加 getter/setter 方法
- 更新构造函数和 toString 方法

**文件**: `ExamVO.java`
- 添加 `gra` 字段（Integer 类型）
- 添加 getter/setter 方法
- 更新 toString 方法

#### 2. Mapper XML
**文件**: `ExamMapper.xml`
- 更新 `ExamVOResultMap` 添加 `gra` 映射
- 更新 `insert` SQL 添加 `GRA` 列
- 更新 `update` SQL 添加 `GRA` 字段的动态更新
- 更新 `selectById` 和 `selectAll` SQL 查询添加 `GRA` 列

#### 3. 前端页面
**文件**: `AdminExam.vue`
- 表格中添加"年级"列显示
- 表单中添加"年级"选择框
- `formData` 中添加 `gra` 字段
- 表单验证规则中添加 `gra` 验证
- 提交数据时转换 `gra` 为 Number 类型
- **修改负责人过滤逻辑**：同时匹配科目类型和年级

### 负责人过滤逻辑升级
```javascript
// 过滤条件：学科组长 + 同科目 + 同年级
return allSubjectLeaders.value.filter(
  teacher => 
    teacher.teachSubject === Number(formData.subjectType) &&
    teacher.gra === Number(formData.gra)
)
```
