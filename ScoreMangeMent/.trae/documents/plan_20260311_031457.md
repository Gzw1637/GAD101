## 计划：修改年级字段为入学年份

### 修改方案

**前端修改**：
- 将年级选择从"高一/高二/高三"改为年份选择
- 年份范围：当前年份往前推 3 年 到 当前年份（例如 2026 年，可选 2023-2026）
- 显示格式：`2024 级` 这样的形式

**后端无需修改**：
- `gra` 字段本身就是 Integer 类型，存储年份（如 2024）
- 数据库和实体类都不需要改动

### 修改文件
- `ScoreFrontend/src/views/AdminExam.vue`
  - 修改年级选择框的选项生成逻辑
  - 使用动态年份选项
  - 显示格式改为"XXX 级"

### 实现逻辑
```javascript
// 生成年份选项（当前年份往前推 3 年到当前年）
const currentYear = new Date().getFullYear()
const gradeOptions = []
for (let i = 0; i <= 3; i++) {
  gradeOptions.push({
    label: `${currentYear - i}级`,
    value: String(currentYear - i)
  })
}
```
