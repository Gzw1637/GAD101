## 问题分析

### 错误原因
在 [`StudentMapper.xml`](file:///c:/Users/26868/Desktop/ScoreMangeMent/ScoreBackend/src/main/resources/mapper/StudentMapper.xml) 的 `updateUser` 方法中（第 105 行），使用了 `userStatus` 属性：

```xml
<if test="userStatus != null">USER_STATUS = #{userStatus},</if>
```

但是 [`Student.java`](file:///c:/Users/26868/Desktop/ScoreMangeMent/ScoreBackend/src/main/java/org/gzw/backend/entity/Student.java) 实体类中**没有 `userStatus` 字段**，只有 `studentStatus` 字段。

### 解决方案

**删除 `updateUser` 中的 `userStatus` 更新**，因为：
1. Student 实体类没有这个字段
2. 学生管理页面修改学生信息时，不需要修改用户的状态
3. 用户状态应该在用户管理模块中管理

### 修改文件
- `ScoreBackend/src/main/resources/mapper/StudentMapper.xml`

### 修改内容
删除 `updateUser` 中的 `userStatus` 判断：

```xml
<update id="updateUser" parameterType="org.gzw.backend.entity.Student">
    UPDATE g_user
    <set>
        <if test="userName != null">USER_NAME = #{userName},</if>
        <if test="name != null">NAME = #{name},</if>
        <if test="password != null and password != ''">PASSWORD = #{password},</if>
        <!-- 删除 userStatus 相关判断 -->
    </set>
    WHERE USER_ID = #{userId}
</update>
```
