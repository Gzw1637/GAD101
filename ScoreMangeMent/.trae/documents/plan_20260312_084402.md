## 计划：创建成绩管理模块

### 数据库表结构
根据截图，`zw_score` 表包含：
- `SCORE_ID` (bigint) - 主键，自增
- `EXAM_ID` (bigint) - 考试 ID
- `STUDENT_ID` (bigint) - 学生 ID
- `SCORE` (decimal(5,1)) - 分数

### 1. 创建实体类
**文件**: `Score.java`
- 位置：`ScoreBackend/src/main/java/org/gzw/backend/entity/Score.java`
- 属性：scoreId, examId, studentId, score
- 手动编写 getter/setter

**文件**: `ScoreVO.java`
- 位置：`ScoreBackend/src/main/java/org/gzw/backend/entity/vo/ScoreVO.java`
- 属性：
  - scoreId, examId, studentId, score
  - examName（考试名称，来自 g_exam 表）
  - subjectType（科目类型，来自 g_exam 表）
  - subjectTypeDesc（科目描述）
  - studentCode（学号，来自 zw_student 表）
  - name（姓名，来自 g_user 表）
  - gra（年级，来自 zw_student 表）
  - cla（班级，来自 zw_student 表）

### 2. Mapper 层
**文件**: `ScoreMapper.java`
- 位置：`ScoreBackend/src/main/java/org/gzw/backend/mapper/ScoreMapper.java`
- 方法：insert, update, deleteById, selectById, selectAll

**文件**: `ScoreMapper.xml`
- 位置：`ScoreBackend/src/main/resources/mapper/ScoreMapper.xml`
- 配置 ResultMap 映射
- 编写 CRUD SQL 语句，关联查询 g_exam、zw_student、g_user 表

### 3. Service 层
**文件**: `ScoreService.java`
- 位置：`ScoreBackend/src/main/java/org/gzw/backend/service/ScoreService.java`

**文件**: `ScoreServiceImpl.java`
- 位置：`ScoreBackend/src/main/java/org/gzw/backend/service/Impl/ScoreServiceImpl.java`

### 4. Controller 层
**文件**: `ScoreController.java`
- 位置：`ScoreBackend/src/main/java/org/gzw/backend/controller/ScoreController.java`
- RESTful API 接口：
  - POST /api/score/add - 添加成绩
  - PUT /api/score/update - 更新成绩
  - DELETE /api/score/delete/{scoreId} - 删除成绩
  - GET /api/score/getById/{scoreId} - 查询单个成绩
  - GET /api/score/list - 查询所有成绩
  - GET /api/score/list-by-exam/{examId} - 按考试 ID 查询成绩列表

### 5. 前端页面
**文件**: `AdminScore.vue`
- 位置：`ScoreFrontend/src/views/AdminScore.vue`
- 功能：
  - 表格显示：序号、考试名称、科目类型、学号、姓名、年级、班级、分数、操作
  - 添加成绩（选择考试、选择学生、输入分数）
  - 编辑成绩
  - 删除成绩
  - 按考试筛选成绩
