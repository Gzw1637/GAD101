## 计划：实现学科查询教师功能

### 分析
- **后端已有接口**：`GET /api/teacher/list` - 查询所有教师（返回 TeacherVO）
- **后端缺失接口**：按学科查询教师的接口
- **前端问题**：使用了错误的接口 `http://localhost:8080/teacher/getAll`

### 实现方案

#### 1. 后端：添加按学科查询教师的接口

**TeacherMapper.java** - 添加方法：
```java
List<TeacherVO> selectBySubject(Integer subjectCode);
```

**TeacherMapper.xml** - 添加 SQL：
```xml
<select id="selectBySubject" resultMap="TeacherVOResultMap" parameterType="java.lang.Integer">
    SELECT t.*, u.USER_NAME, u.NAME,
           sex.CODE_DESC as SEX_DESC,
           ts.CODE_DESC as TEACHER_STATUS_DESC,
           tt.CODE_DESC as TEACHER_TYPE_DESC,
           sub.CODE_DESC as TEACH_SUBJECT_DESC
    FROM zw_teacher t
    LEFT JOIN g_user u ON t.USER_ID = u.USER_ID
    LEFT JOIN g_code sex ON t.SEX = sex.CODE_ID
    LEFT JOIN g_code ts ON t.TEACHER_STATUS = ts.CODE_ID
    LEFT JOIN g_code tt ON t.TEACHER_TYPE = tt.CODE_ID
    LEFT JOIN g_code sub ON t.TEACH_SUBJECT = sub.CODE_ID
    WHERE t.TEACH_SUBJECT = #{subjectCode}
    ORDER BY u.USER_NAME
</select>
```

**TeacherService.java** - 添加方法：
```java
List<TeacherVO> getTeachersBySubject(Integer subjectCode);
```

**TeacherController.java** - 添加接口：
```java

```
