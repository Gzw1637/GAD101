## 计划：重构成绩管理表单，拆分学生字段

### 修改方案

#### 前端：AdminScore.vue

**表单字段调整**：
1. **考试选择**（保持不变）
   - 下拉框选择考试
   
2. **学生信息**（拆分为多个字段）：
   - **年级选择**：下拉框（2026 级、2025 级、2024 级、2023 级）
   - **班级选择**：下拉框（1 班、2 班、3 班...）
   - **学号选择**：下拉框（根据年级 + 班级过滤后的学号）
   - **姓名显示**：只读文本框（根据学号自动显示对应姓名）

3. **分数**（保持不变）
   - 数字输入框

**实现逻辑**：
```javascript
// 表单数据
formData = {
  examId: '',
  studentId: '',
  gra: '',        // 新增
  cla: '',        // 新增
  studentCode: '', // 新增
  score: 0
}

// 过滤逻辑
1. 选择年级后，过滤出该年级的班级选项
2. 选择年级 + 班级后，过滤出该班级的学生列表
3. 选择学号后，自动填充学生 ID 和姓名
```

**级联选择流程**：
```
选择年级 → 选择班级 → 选择学号 → 自动显示姓名
```

### 修改文件
- `ScoreFrontend/src/views/AdminScore.vue` - 重构表单

### 优势
1. ✅ 字段独立，便于批量导入时映射
2. ✅ 级联过滤，减少选择范围
3. ✅ 清晰展示学生信息结构
4. ✅ 为后续批量导入功能做准备
