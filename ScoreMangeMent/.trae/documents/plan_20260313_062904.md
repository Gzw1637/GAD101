## 计划：根据学生数据动态生成年级和班级选项

### 修改方案

#### 前端：AdminScore.vue

**修改内容**：
1. **年级选项**：从学生列表中提取所有不重复的年级，动态生成选项
2. **班级选项**：根据所选年级，从该年级学生中提取所有不重复的班级

**实现逻辑**：
```javascript
// 计算属性：获取所有不重复的年级选项
const gradeOptions = computed(() => {
  const grades = [...new Set(studentList.value.map(s => s.gra))]
    .filter(g => g !== null && g !== undefined)
    .sort((a, b) => b - a) // 降序排列，新的年级在前
  return grades.map(g => ({
    label: `${g}级`,
    value: String(g)
  }))
})

// 计算属性：根据所选年级获取班级选项
const classOptions = computed(() => {
  if (!formData.gra) return []
  const classes = [...new Set(
    studentList.value
      .filter(s => String(s.gra) === String(formData.gra))
      .map(s => s.cla)
      .filter(c => c !== null && c !== undefined)
  )].sort((a, b) => a - b)
  return classes.map(c => ({
    label: `${c}班`,
    value: String(c)
  }))
})
```

### 优势
1. ✅ 年级选项来自实际数据，不会有多余选项
2. ✅ 班级选项根据年级动态过滤，更精准
3. ✅ 支持历史年份数据
4. ✅ 自动去重和排序
