## 修复文件上传 Content-Type 错误

### 问题根源
`request.js` 的请求拦截器中，第 13 行强制设置了所有请求的 Content-Type 为 `application/json;charset=utf-8`，导致文件上传请求被错误地设置为 JSON 格式。

### 解决方案
修改 `request.js` 的拦截器逻辑：
1. 判断请求数据是否为 FormData 类型
2. 如果是 FormData（文件上传），则不设置 Content-Type
3. 让浏览器自动设置正确的 `multipart/form-data` 边界

### 修改文件
- `ScoreFrontend/src/utils/request.js` 第 12-18 行

### 修改代码
```javascript
// 修改前：
config.headers["Content-Type"] = "application/json;charset=utf-8";

// 修改后：
if (!config.data instanceof FormData) {
    config.headers["Content-Type"] = "application/json;charset=utf-8";
}
```
