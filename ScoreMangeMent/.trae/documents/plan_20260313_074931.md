## 批量修复所有管理页面的分页问题

### 问题总结
检查发现 6 个 Vue 文件都存在与 AdminStudent.vue 相同的分页问题：
- 数据加载后直接赋值给列表数组
- 没有根据 `currentPage` 和 `pageSize` 进行切片
- 导致表格显示所有数据，分页控件形同虚设

### 修复方案
对每个文件的数据加载方法添加前端分页切片逻辑：
```javascript
// 先排序/过滤
const sortedList = response.data.sort(...)
// 设置总数
total.value = sortedList.length
// 根据当前页和每页数量进行切片
const startIndex = (currentPage.value - 1) * pageSize.value
const endIndex = startIndex + pageSize.value
list.value = sortedList.slice(startIndex, endIndex)
```

### 需要修复的文件及方法
1. **AdminUser.vue**: `loadUserList`, `handleSearch`
2. **AdminTeacher.vue**: `loadTeacherList`, `handleSearch`
3. **AdminExam.vue**: `loadExamList`, `handleSearch`
4. **AdminScore.vue**: `loadScoreList`
5. **AdminSubjectDetail.vue**: `loadTeacherList`
6. **AdminAdvice.vue**: `loadAdviceList`, `handleSearch`

### 修复顺序
按优先级依次修复每个文件，每个文件修改后保持与 AdminStudent.vue 一致的分页逻辑。
