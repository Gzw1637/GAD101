## 修复分页后序号重置问题

### 问题分析
当前所有管理页面的表格序号列都使用 `<el-table-column type="index" />`，它始终从 1 开始计数，没有考虑分页。

### 解决方案
将序号列从 `type="index"` 改为自定义模板，根据当前页码和每页数量计算正确的序号：

```javascript
// 第 1 页：序号 1-10
// 第 2 页：序号 11-20
// 第 3 页：序号 21-30
// 计算公式：(currentPage - 1) * pageSize + rowIndex + 1
```

### 需要修改的文件
所有带有序号列的管理页面：
1. AdminUser.vue
2. AdminTeacher.vue
3. AdminExam.vue
4. AdminScore.vue
5. AdminSubjectDetail.vue
6. AdminAdvice.vue
7. AdminStudent.vue（已经修复过分页逻辑）

### 修改方式
将 `<el-table-column type="index" />` 改为：
```vue
<el-table-column label="序号" width="60">
  <template #default="scope">
    {{ (currentPage - 1) * pageSize + scope.$index + 1 }}
  </template>
</el-table-column>
```
