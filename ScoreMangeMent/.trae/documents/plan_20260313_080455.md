## 实现多条件复合查询功能

### 需求分析
用户希望在用户管理页面实现多条件筛选：
1. 按角色筛选（如：老师、学生）
2. 按状态筛选（如：有效、无效）
3. 支持组合查询（如：老师 + 有效）

### 实现方案

#### 1. 后端修改
**新增接口**：`POST /api/user/search/advanced`
- 接收一个包含多个筛选条件的 JSON 对象
- 支持的条件：`role`（角色）、`userStatus`（状态）、`name`（姓名）
- 返回符合条件的用户列表

**修改 UserService 和 UserMapper**：
- 添加动态 SQL 查询方法
- 根据传入的条件动态构建 WHERE 子句

#### 2. 前端修改（AdminUser.vue）
**添加筛选组件**：
- 角色下拉框：全部/学生/老师/管理员
- 状态下拉框：全部/有效/无效
- 保留原有的姓名搜索框
- 添加"搜索"按钮和"重置"按钮

**修改搜索逻辑**：
- 将单条件搜索改为多条件复合搜索
- 调用新的后端接口
- 支持任意条件组合查询

### 具体实现步骤

#### 后端：
1. 在 UserMapper.java 添加 `searchByConditions` 方法
2. 在 UserMapper.xml 添加动态 SQL
3. 在 UserService 添加业务逻辑
4. 在 UserController 添加新的接口

#### 前端：
1. 添加角色和状态下拉框
2. 修改搜索栏布局
3. 实现多条件搜索逻辑
4. 实现重置功能

### 预期效果
用户可以：
- 只按角色筛选：查看所有老师
- 只按状态筛选：查看所有有效用户
- 组合筛选：查看所有有效的老师
- 组合筛选：查看所有有效的学生
- 支持清空所有条件
