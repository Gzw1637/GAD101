## 实现学生管理多条件复合查询功能

### 需求分析
仿照用户管理，为学生管理添加复合查询功能：
- 按年级筛选（如：2019 级、2020 级等）
- 按班级筛选（如：1 班、2 班等）
- 按姓名筛选
- 支持任意条件组合查询

### 实现方案

#### 1. 后端修改
**StudentMapper.java**：
- 添加 `searchByConditions` 方法，参数：`gra`, `cla`, `name`

**StudentMapper.xml**：
- 添加动态 SQL 查询，支持按年级、班级、姓名筛选

**StudentService.java & StudentServiceImpl.java**：
- 添加 `searchStudentsByConditions` 业务方法

**StudentController.java**：
- 添加 `POST /api/student/search/advanced` 接口

#### 2. 前端修改（AdminStudent.vue）
**搜索栏 UI**：
- 姓名输入框（带清除按钮）
- 年级下拉框（动态生成）
- 班级下拉框（动态生成）
- 搜索按钮
- 重置按钮

**搜索逻辑**：
- 调用新的 `/api/student/search/advanced` 接口
- 支持任意条件组合查询
- 搜索后重置到第一页

### 具体实现步骤

#### 后端：
1. StudentMapper.java 添加 searchByConditions 方法
2. StudentMapper.xml 添加动态 SQL
3. StudentService 添加业务逻辑
4. StudentController 添加新接口

#### 前端：
1. 修改搜索栏布局，添加年级、班级下拉框
2. 添加筛选变量
3. 修改搜索逻辑，调用新接口
4. 实现重置功能
