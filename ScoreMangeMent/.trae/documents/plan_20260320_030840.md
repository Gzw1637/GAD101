# 创建意见管理模块完整代码

## 实施计划

### 1. 实体类创建（`org.gzw.backend.entity`）
- **ZwAdvice.java** - 意见主表实体
  - 字段：adviceId, recipientId, senderId, adviceType, adviceStatus, adviceDesc, senderType, createTime
- **ZwAdviceImage.java** - 意见图片附表实体
  - 字段：imageId, adviceId, imageUrl, createTime

### 2. Mapper 层创建（`org.gzw.backend.mapper` + `resources/mapper`）
- **ZwAdviceMapper.java** - 意见 Mapper 接口
  - 方法：insert, update, deleteById, selectById, selectAll, selectByRecipientId, selectBySenderId
- **ZwAdviceMapper.xml** - MyBatis XML 配置文件
  - ResultMap 映射、动态 SQL、多条件查询
- **ZwAdviceImageMapper.java** - 图片 Mapper 接口
  - 方法：insert, update, deleteById, deleteByAdviceId, selectByAdviceId
- **ZwAdviceImageMapper.xml** - 图片 MyBatis XML 配置文件

### 3. Service 层创建（`org.gzw.backend.service` + `Impl`）
- **ZwAdviceService.java** - 服务接口
  - CRUD 方法 + 图片上传下载方法
- **ZwAdviceServiceImpl.java** - 服务实现类
  - 实现业务逻辑、事务管理、图片存储处理
- **ZwAdviceImageService.java** - 图片服务接口
- **ZwAdviceImageServiceImpl.java** - 图片服务实现类

### 4. Controller 层创建（`org.gzw.backend.controller`）
- **ZwAdviceController.java** - 意见控制器
  - RESTful 接口：
    - POST `/api/advice/add` - 添加意见
    - PUT `/api/advice/update` - 更新意见
    - DELETE `/api/advice/delete/{id}` - 删除意见
    - GET `/api/advice/{id}` - 获取意见详情
    - GET `/api/advice/list` - 获取意见列表
    - GET `/api/advice/my` - 获取我的意见
    - POST `/api/advice/upload/{adviceId}` - 上传图片
    - GET `/api/advice/download/{imageId}` - 下载图片
    - DELETE `/api/advice/image/{imageId}` - 删除图片

### 5. 图片上传配置
- 配置文件上传路径（application.yml）
- 添加 MultipartFile 处理逻辑
- 生成唯一文件名避免冲突
- 返回图片访问 URL

### 6. 代码特点
- 遵循项目现有代码风格（手动编写 getter/setter）
- 使用 MyBatis 原生 XML 配置
- 使用 @Transactional 保证事务
- 统一 Result 返回格式
- 支持批量图片上传
- 图片与意见关联管理
