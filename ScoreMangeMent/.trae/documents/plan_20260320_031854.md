# 更新 AdminAdvice.vue 页面计划

## 实施计划

### 页面功能
1. **查询所有意见** - 表格展示意见列表
2. **添加意见** - 对话框表单
3. **编辑意见** - 对话框表单回显
4. **删除意见** - 确认后删除
5. **搜索功能** - 按条件筛选意见
6. **分页功能** - 前端分页

### 后端接口调用
- `GET /api/advice/list` - 获取所有意见
- `GET /api/advice/getById/{id}` - 获取意见详情
- `POST /api/advice/add` - 添加意见
- `PUT /api/advice/update` - 更新意见
- `DELETE /api/advice/delete/{id}` - 删除意见
- `GET /api/student/list` - 获取学生列表（用于映射）
- `GET /api/teacher/list` - 获取教师列表（用于映射）

### 代码特点
1. 使用 Vue 3 Composition API（`<script setup>`）
2. 使用 Element Plus 组件库
3. 使用统一的 axios 封装（request.js）
4. 表格 + 分页 + 对话框模式
5. 支持搜索、增删改查
6. 自动映射发送者和接收者姓名
7. 字典值翻译（意见类型、状态等）
