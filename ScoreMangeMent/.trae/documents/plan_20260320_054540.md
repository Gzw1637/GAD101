# 修复编译错误

## 问题分析
在 `ZwAdviceServiceImpl.java` 第 155 行调用了 `zwAdviceMapper.selectByAdviceId(adviceId)` 方法，但该方法在 `ZwAdviceMapper` 接口中不存在。

## 解决方案
在 `ZwAdviceMapper` 接口中添加 `selectByAdviceId` 方法，并在 `ZwAdviceMapper.xml` 中添加对应的 SQL 查询。

### 修改内容：
1. **ZwAdviceMapper.java** - 添加方法声明：
   ```java
   List<ZwAdviceVO> selectByAdviceId(Long adviceId);
   ```

2. **ZwAdviceMapper.xml** - 添加对应的 SQL 查询（与 selectAll 类似，但添加 WHERE 条件）
