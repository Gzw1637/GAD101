# 修复 Controller 中的类型不匹配问题

## 问题分析
ZwAdviceController 中多个方法使用了错误的返回类型：
- Service 层返回的是 `ZwAdviceVO` 和 `List<ZwAdviceVO>`
- Controller 层声明的返回类型是 `ZwAdvice` 和 `List<ZwAdvice>`

## 解决方案
修改 ZwAdviceController.java 中所有相关方法的返回类型和变量类型：

1. **getAdviceById** (第 71-78 行)
   - 返回类型改为 `Result<ZwAdviceVO>`
   - 变量类型改为 `ZwAdviceVO`

2. **getAllAdvices** (第 80-84 行)
   - 返回类型改为 `Result<List<ZwAdviceVO>>`
   - 变量类型改为 `List<ZwAdviceVO>`

3. **getAdvicesByRecipientId** (第 86-90 行)
   - 返回类型改为 `Result<List<ZwAdviceVO>>`
   - 变量类型改为 `List<ZwAdviceVO>`

4. **getAdvicesBySenderId** (第 92-96 行)
   - 返回类型改为 `Result<List<ZwAdviceVO>>`
   - 变量类型改为 `List<ZwAdviceVO>`

5. **searchAdvicesByConditions** (第 98-106 行)
   - 返回类型改为 `Result<List<ZwAdviceVO>>`
   - 变量类型改为 `List<ZwAdviceVO>`
