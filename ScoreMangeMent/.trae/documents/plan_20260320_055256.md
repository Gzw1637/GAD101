# 在意见管理中添加图片显示功能

## 问题分析
1. `zw_advice_image` 表已经存在，用于存储意见关联的图片
2. 但 `ZwAdviceVO` 没有包含图片列表字段
3. Mapper XML 查询没有关联图片表
4. 前端页面也没有显示图片

## 解决方案

### 1. 修改 ZwAdviceVO
添加图片列表字段：
```java
private List<String> imageUrls;  // 图片 URL 列表
```

### 2. 修改 ZwAdviceMapper.xml
在查询语句中 LEFT JOIN `zw_advice_image` 表，使用 GROUP_CONCAT 聚合图片 URL

### 3. 修改前端 AdminAdvice.vue
- 在表格中添加"图片"列
- 显示图片缩略图，点击可放大查看
- 使用 Element Plus 的图片预览组件

## 修改内容

### 后端修改：
- `ZwAdviceVO.java` - 添加 imageUrls 字段
- `ZwAdviceMapper.xml` - 修改所有查询，关联图片表

### 前端修改：
- `AdminAdvice.vue` - 添加图片列显示和预览功能
