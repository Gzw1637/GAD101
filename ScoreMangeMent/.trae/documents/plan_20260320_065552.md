# 修复双重 Layout 嵌套问题

## 问题原因
StudentScore.vue 页面中仍然包含了 Layout 组件，导致：
- Student.vue 使用了一次 Layout
- StudentScore.vue 又使用了一次 Layout
- 结果：双重导航栏 + 双重侧边栏

## 解决方案
StudentScore.vue 应该只是一个纯粹的内容组件，不包含任何 Layout。它会被渲染到 Student.vue 的 `<RouterView />` 中。

当前 StudentScore.vue 已经是正确的（已经移除了 Layout），但可能需要重新编译或刷新浏览器。

## 需要确认
检查 StudentScore.vue 是否还有 Layout 相关代码，如有则删除。
