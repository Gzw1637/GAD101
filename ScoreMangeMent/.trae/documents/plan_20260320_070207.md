# 修复 Student.vue 双重 Layout 问题

## 问题分析
Student.vue 确实只使用了一次 Layout 组件，但问题可能出在：
1. 路由配置中，`/student` 的子路由配置可能有误
2. 或者 Layout 组件本身的实现有问题

## 检查发现
查看 Student.vue 的代码，确实只使用了一次 Layout，结构是正确的。

但问题可能是：**Layout 组件内部是否又渲染了一次 RouterView？**

如果是这样，那么：
- Layout 渲染一次（包含侧边栏和头部）
- Layout 内部的 RouterView 渲染 Student.vue
- Student.vue 中的 RouterView 又渲染 StudentScore.vue

这样就形成了三层嵌套！

## 解决方案
检查 Layout.vue 组件，看它是否包含了 RouterView。如果有，需要移除。
