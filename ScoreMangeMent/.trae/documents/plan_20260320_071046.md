# 修复 StudentScore.vue 的多余 div 结束标签

## 问题原因
第 97 行有多余的 `</div>` 标签

模板结构：
```
第 2 行：<div class="student-score-content">     ← 第 1 个 div 开始
第 3 行：  <el-card>                             ← el-card 开始
...
第 95 行：  </el-card>                           ← el-card 结束
第 96 行：</div>                                  ← 第 1 个 div 结束 ✓
第 97 行：</div>                                  ← 多余的！❌
```

## 解决方案
删除第 97 行的 `</div>`
