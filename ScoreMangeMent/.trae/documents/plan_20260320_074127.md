## 修复计划

### 问题原因
`g_exam` 数据库表没有 `REMARK` 字段，但 ScoreMapper.xml 的 SQL 查询中尝试查询该字段，导致 SQL 语法错误。

### 解决方案
修改 `ScoreMapper.xml`，移除所有 SQL 查询中的 `e.REMARK` 字段。

### 需要修改的文件
- `ScoreBackend/src/main/resources/mapper/ScoreMapper.xml`
  - 移除 `selectByStudentId` 查询中的 `e.REMARK`
  - 移除 `selectByStudentIdAndFilters` 查询中的 `e.REMARK`

### 影响
- 前端"备注"列将显示空值或"-"
- 不影响其他功能正常使用
