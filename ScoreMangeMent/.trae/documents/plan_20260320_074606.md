## 修复计划

### 问题分析
当前端调用 `/api/exam/list` 接口时，返回所有年级的考试。需要修改为只返回当前学生所在年级的考试。

### 解决方案
1. 修改后端 `ScoreController`，添加一个新的接口 `/api/exam/my-list`，专门用于学生端获取考试列表
2. 该接口会从 Token 中获取当前登录学生的 userId，然后查询学生信息获取年级（gra）
3. 只返回该年级对应的考试列表
4. 前端修改调用接口为 `/api/exam/my-list`

### 需要修改的文件
**后端：**
- `ScoreBackend/src/main/java/org/gzw/backend/controller/ExamController.java` - 添加 `/api/exam/my-list` 接口
- 或者新建一个接口专门服务于学生端

**前端：**
- `ScoreFrontend/src/views/StudentScore.vue` - 修改 loadExamList 方法调用新接口

### 技术要点
- 从 JWT Token 中获取 userId
- 通过 userId 查询学生的 gra（年级）
- 查询考试时添加年级过滤条件
