## 学生端意见箱功能实现计划

### 功能设计
学生端意见箱分为两个子菜单：
1. **发件箱** - 显示学生发送的所有意见（支持查看已发送的意见）
2. **收件箱** - 显示学生收到的所有意见（支持查看、回复）

### 实现步骤

#### 1. 后端修改
**文件：** `ZwAdviceController.java`
- 添加接口：`/api/advice/my/sent` - 获取当前用户发送的意见
- 添加接口：`/api/advice/my/received` - 获取当前用户收到的意见
- 添加接口：`/api/advice/reply` - 回复意见

**文件：** `ZwAdviceService.java` 和 `ZwAdviceServiceImpl.java`
- 实现上述三个服务方法

**文件：** `ZwAdviceMapper.xml`
- 添加 `selectBySenderId` 查询
- 添加 `selectByRecipientId` 查询（带状态更新）

#### 2. 前端路由修改
**文件：** `src/router/index.js`
```javascript
{path: '/student', name: 'Student', component: Student, children: [
    {path: 'score', name: 'StudentScore', component: StudentScore},
    {path: 'advice/sent', name: 'StudentAdviceSent', component: StudentAdviceSent},
    {path: 'advice/received', name: 'StudentAdviceReceived', component: StudentAdviceReceived}
]}
```

#### 3. 前端菜单修改
**文件：** `src/views/Student.vue`
- 将"意见箱"改为 el-sub-menu，包含两个子菜单项：
  - 发件箱 (`/student/advice/sent`)
  - 收件箱 (`/student/advice/received`)

#### 4. 前端页面组件
**文件：** `src/views/StudentAdviceSent.vue`（新建）
- 显示已发送意见列表（类似 AdminAdvice 但简化）
- 包含搜索、删除功能
- 支持富文本编辑器发件（参考你提供的截图样式）

**文件：** `src/views/StudentAdviceReceived.vue`（新建）
- 显示已收到意见列表
- 支持标记已读、回复功能
- 支持查看意见详情和附件图片

#### 5. 发件页面设计（参考你的截图）
- 顶部工具栏：图片上传、插入、导入文档等
- 富文本编辑区：输入正文
- 底部显示当前登录用户信息（头像、姓名、邮箱）
- 选择接收者（教师或其他学生）
- 选择意见类型（教学/班级/生活/学习/其它）
- 实名/匿名选项

### 技术要点
1. 使用 JWT 获取当前登录用户 ID
2. 发件时支持图片上传（调用现有 `/api/advice/upload/{adviceId}` 接口）
3. 收件箱查看时自动标记为已读
4. 支持分页显示
5. 前端使用 Vue3 + Element Plus
