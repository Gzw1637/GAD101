**问题分析**
发送成功了，但是没看到原本写出来的富文本效果。这是因为我们在提交时只提取了纯文本内容，没有保留富文本格式。

**解决方案**
修改前端代码，将 Quill 编辑器的 Delta 对象转换为 HTML 字符串，而不是纯文本，这样就能保留富文本格式。

**修改的文件**
- `ScoreFrontend/src/views/StudentAdviceSent.vue`

**具体实现**
1. 在 `StudentAdviceSent.vue` 文件中，添加一个 Quill 实例引用
2. 修改 `handleSubmit` 函数，使用 Quill 实例的 `root.innerHTML` 获取 HTML 内容
3. 确保发送到后端的 `adviceDesc` 是 HTML 字符串

**修改步骤**
1. 在模板中为 QuillEditor 添加 ref 属性
2. 在 script 中创建 ref 引用
3. 修改 `handleSubmit` 函数，使用 `quillEditorRef.value.getEditor().root.innerHTML` 获取 HTML 内容
4. 确保提交的数据中 `adviceDesc` 是 HTML 字符串

这样后端存储的就是 HTML 字符串，前端在显示时也能正确渲染富文本效果。
