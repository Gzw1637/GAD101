**功能开发与修复计划**

## 1. 富文本编辑器提交与展示修复

### 问题分析
当前提交富文本后，内容变为 [object Object]，详情页无法展示样式。这是因为：
- 前端提交的是 Delta 对象，而不是 HTML 字符串
- 即使转换为字符串，也是提取的纯文本，丢失了样式信息

### 解决方案
1. **修改前端提交逻辑**：
   - 使用 Quill 编辑器的 `root.innerHTML` 获取完整的 HTML 内容
   - 确保提交给后端的 `adviceDesc` 是 HTML 字符串

2. **保持后端结构不变**：
   - 后端 `ZwAdvice` 实体类中 `adviceDesc` 保持 String 类型
   - 数据库存储为 HTML 文本（已改为 TEXT/MEDIUMTEXT）

3. **修改前端展示逻辑**：
   - 收件箱详情页使用 `v-html` 指令渲染 `adviceDesc`
   - 确保正确显示富文本样式（如加粗、换行、列表等）

## 2. 发意见页收件人自动填充姓名功能

### 功能需求
1. 表单新增「收件人用户名」输入框，下方新增「收件人姓名」展示框（初始禁用）
2. 用户名输入框失焦或回车时，查询用户真实姓名
3. 查询成功后，自动填充姓名到「收件人姓名」框，并设置该字段为只读
4. 提交表单时，需传递收件人用户ID（或 userName）与姓名

### 解决方案
1. **修改表单结构**：
   - 添加「收件人用户名」输入框
   - 添加「收件人姓名」展示框，初始禁用

2. **添加查询逻辑**：
   - 实现用户名输入框失焦或回车时的查询功能
   - 调用后端 API 查询用户信息

3. **自动填充逻辑**：
   - 查询成功后，自动填充姓名到「收件人姓名」框
   - 设置该字段为只读

4. **修改提交逻辑**：
   - 确保提交时传递正确的收件人信息
