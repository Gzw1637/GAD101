**问题分析**
用户输入用户名后没有显示姓名，系统显示"未找到该用户，请检查用户名是否正确"。这是因为：

* 前端调用的是 `/api/user/search?name=${userName}` API

* 后端 `selectByName` 方法是根据 `NAME` 字段（姓名）进行模糊搜索的

* 当用户输入用户名 "ST2019010001" 时，系统会在姓名字段中搜索，所以找不到用户

**解决方案**

1. **后端修改**：在 UserController.java 中添加一个新的 API，用于根据用户名搜索用户
2. **前端修改**：修改前端代码，使用新的 API 进行用户名搜索

**修改的文件**

1. `ScoreBackend/src/main/java/org/gzw/backend/controller/UserController.java`：添加根据用户名搜索的 API
2. `ScoreFrontend/src/views/StudentAdviceSent.vue`：修改搜索函数，使用新的 API

**具体实现**

1. **后端修改**：

   * 在 UserController.java 中添加 `@GetMapping("/searchByUserName")` 方法

   * 调用 userService 中已有的方法（如果有）或添加新方法

2. **前端修改**：

   * 修改 `searchUserByUserName` 函数，调用新的 API

   * 确保传递正确的参数

1. 先修改后端，添加根据用户名搜索的 API
