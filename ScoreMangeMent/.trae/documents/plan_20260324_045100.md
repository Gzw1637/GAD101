## TeacherScore.vue 设计方案

### 功能需求
- 老师可以根据年级和学科查询单科成绩
- 显示成绩列表，包括学生信息、分数、排名等
- 提供搜索和筛选功能
- 支持分页显示

### 界面设计
1. **页面标题**：成绩查询
2. **搜索栏**：
   - 年级选择器
   - 学科选择器
   - 考试名称搜索框
   - 搜索按钮
   - 重置按钮
3. **成绩表格**：
   - 序号
   - 学生姓名
   - 学号
   - 班级
   - 分数
   - 班级排名
   - 年级排名
   - 考试时间
4. **分页控件**：显示总条数、每页条数选择、页码导航

### 数据结构
- **筛选条件**：年级、学科、考试名称
- **成绩列表**：包含学生信息、分数、排名等
- **分页数据**：当前页码、每页条数、总条数

### 实现步骤
1. **创建组件文件**：`ScoreFrontend/src/views/TeacherScore.vue`
2. **设计模板结构**：包含卡片、搜索栏、表格、分页
3. **实现数据逻辑**：
   - 加载年级和学科选项
   - 实现成绩查询接口调用
   - 处理搜索和筛选逻辑
   - 实现分页功能
4. **添加样式**：确保界面美观

### API 接口
- 成绩查询接口：`/api/score/teacher`（需要根据年级和学科参数）
- 年级和学科选项可以从现有数据中获取

### 技术要点
- 使用 Vue 3 Composition API
- 使用 Element Plus 组件库
- 实现响应式数据管理
- 处理异步请求和错误
- 优化用户体验
