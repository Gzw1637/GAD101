## 修复计划

### 1. 问题分析
- 错误信息：`Method parameter 'teacherId': Failed to convert value of type 'java.lang.String' to required type 'java.lang.Long'; For input string: "current"`
- 错误原因：前端尝试访问 `/api/teacher/current` 接口，但后端的 `/api/teacher/{teacherId}` 接口期望的是一个 Long 类型的 teacherId 参数，而不是字符串 "current"

### 2. 解决方案
- 修改 TeacherPersonal.vue 组件，首先调用 `/api/userInfo` 接口获取当前用户的 userId
- 然后根据 userId 调用 `/api/teacher/{userId}` 接口获取教师的详细信息
- 调整表单数据的处理逻辑，确保与后端接口的参数要求一致

### 3. 验证步骤
- 确保教师个人信息页面能够正常加载
- 确保能够成功获取和修改个人信息
- 确保表单验证和错误处理正常工作
