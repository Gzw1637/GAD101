# 实现修改密码功能的计划

## 1. 后端实现

### 1.1 在 UserService.java 中添加修改密码的方法
- 添加 `changePassword` 方法，接收用户名、旧密码和新密码作为参数
- 验证旧密码是否正确
- 对新密码进行 BCrypt 加密
- 更新用户密码

### 1.2 在 UserServiceImpl.java 中实现修改密码的方法
- 实现 `changePassword` 方法的具体逻辑
- 使用 `selectByUserName` 方法获取用户信息
- 使用 BCrypt 验证旧密码
- 对新密码进行加密并更新

### 1.3 在 UserController.java 中添加修改密码的接口
- 添加 `POST /api/user/change-password` 接口
- 接收包含旧密码和新密码的请求体
- 从 JWT token 中获取当前用户的用户名
- 调用 `changePassword` 方法修改密码
- 返回成功或失败的响应

## 2. 前端修改

### 2.1 修改 ChangePassword.vue 组件
- 确保请求路径正确
- 确保请求方法为 POST
- 确保请求体格式正确

## 3. 测试和优化

### 3.1 测试修改密码功能
- 测试密码修改成功的情况

- 测试新密码格式不符合要求的情况

### 3.2 优化用户体验

## 技术要点

- 使用 BCrypt 进行密码加密和验证
- 从 JWT token 中获取当前用户信息
- 实现前后端的数据传输和验证
- 确保 API 接口的安全性
