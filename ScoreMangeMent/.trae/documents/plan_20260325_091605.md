# 基于通义千问的教师端 AI 成绩分析实施计划

> 💰 **成本预估**：3-5 元/月（新用户有 300 元免费额度，可用近 1 年）

---

## 📋 第一阶段：准备工作（30 分钟）

### 1. 申请阿里云 API Key
- 访问：https://dashscope.console.aliyun.com/
- 注册/登录阿里云账号
- 开通**DashScope 灵积模型服务**
- 创建 API Key（用于通义千问）
- 开通**OCR 服务**（阿里云控制台）
- 获取 OCR API Key

### 2. 添加 Maven 依赖
在 `pom.xml` 中添加：
```xml
<!-- 阿里云 DashScope SDK（通义千问） -->
<dependency>
    <groupId>com.alibaba</groupId>
    <artifactId>dashscope-sdk-java</artifactId>
    <version>2.15.0</version>
</dependency>

<!-- 阿里云 OCR SDK -->
<dependency>
    <groupId>com.aliyun</groupId>
    <artifactId>ocr20210707</artifactId>
    <version>1.0.0</version>
</dependency>
```

## 📋 第二阶段：后端开发（4-6 小时）

### 1. 配置文件增强
**文件**：`application.yml`

添加配置：
```yaml
aliyun:
  ai:
    # 通义千问配置
    qwen:
      api-key: ${QWEN_API_KEY}  # 环境变量
      model: qwen-plus  # 性价比高，0.002 元/千 tokens
      base-url: https://dashscope.aliyuncs.com/api/v1
    # OCR 配置
    ocr:
      api-key: ${ALIYUN_OCR_KEY}
      region: cn-shanghai
  # 文件上传配置
  oss:
    upload-path: C:/uploads/exam-papers
    base-url: /api/exam/papers
```

### 2. 创建实体类（30 分钟）

**文件位置**：`entity/`

- `AiAnalysisRecord.java` - AI 分析记录
  - 字段：analysisId, examId, teacherId, analysisType, analysisContent, studentId, imageUrl, createTime

- `StudentExamPaper.java` - 学生试卷
  - 字段：paperId, studentId, examId, paperImageUrl, ocrResult, aiAnalysis, uploadTime

**文件位置**：`entity/vo/`

- `AiAnalysisVO.java` - AI 分析结果展示
  - 字段：班级平均分、最高分、最低分、进步情况、分数分布、AI 评语、学生个体分析等

### 3. 创建 Mapper 层（30 分钟）

**文件位置**：`mapper/`

- `AiAnalysisMapper.java`
- `StudentExamPaperMapper.java`

**文件位置**：`resources/mapper/`

- `AiAnalysisMapper.xml`
- `StudentExamPaperMapper.xml`

### 4. 创建 Service 层（2-3 小时）

**文件位置**：`service/`

- `AiAnalysisService.java`（接口）
  - `analyzeClassPerformance(Long examId)` - 班级成绩分析
  - `analyzeStudentPaper(Long paperId)` - 试卷识图分析
  - `generateReport(Long examId, Long studentId)` - 生成综合报告
  - `getAnalysisHistory(Long teacherId)` - 获取分析历史

**文件位置**：`service/Impl/`

- `AiAnalysisServiceImpl.java`（实现类）

**文件位置**：`config/`

- `AliyunConfig.java` - 阿里云配置类
  - 配置 DashScope 客户端
  - 配置 OCR 客户端

**文件位置**：`util/`

- `QwenAiClient.java` - 通义千问 API 调用工具
  - 封装 AI 对话调用
  - 编写成绩分析 Prompt 模板
  - 处理流式响应

- `OcrService.java` - OCR 识别服务
  - 试卷图片文字识别
  - 手写体优化识别

### 5. 创建 Controller 层（1 小时）

**文件位置**：`controller/`

- `AiAnalysisController.java`

接口列表：
```java
// 班级成绩分析
@PostMapping("/class")
public Result<AiAnalysisVO> analyzeClass(@RequestBody AnalysisRequest request);

// 上传试卷图片
@PostMapping("/paper/upload")
public Result<PaperUploadResponse> uploadPaper(@RequestParam("file") MultipartFile file,
                                                @RequestParam("studentId") Long studentId,
                                                @RequestParam("examId") Long examId);

// 试卷识图分析
@PostMapping("/paper/analyze")
public Result<AiAnalysisVO> analyzePaper(@RequestParam("paperId") Long paperId);

// 获取分析报告
@GetMapping("/report/{examId}")
public Result<AiAnalysisVO> getReport(@PathVariable Long examId);

// 获取分析历史
@GetMapping("/history")
public Result<List<AiAnalysisRecord>> getHistory();
```

## 📋 第四阶段：AI Prompt 优化（1-2 小时）

### 成绩分析 Prompt 模板

```java
// QwenAiClient.java 中的 Prompt 示例
String prompt = """
你是一位经验丰富的中学教师，请根据以下班级成绩数据进行分析：

【考试信息】
考试名称：%s
科目：%s
考试时间：%s
班级：%s

【成绩数据】
平均分：%.2f
最高分：%d
最低分：%d
及格率：%.2f%%
优秀率：%.2f%%

【分数段分布】
90 分以上：%d 人
80-89 分：%d 人
70-79 分：%d 人
60-69 分：%d 人
60 分以下：%d 人

【历次考试对比】
上次考试平均分：%.2f
变化：%.2f 分（进步/退步）

请生成一份分析报告，包括：
1. 班级整体表现评价（100 字以内）
2. 指出主要问题和薄弱环节
3. 给出 3 条具体教学建议
4. 标注进步明显的学生（前 5 名）
5. 标注需要关注的学生（后 5 名）

要求：语言简洁、专业，适合教师阅读。
""";
```
