# 修改方案：使用 HTTP 调用替代 SDK

## 🎯 目标
移除无法下载的阿里云 SDK 依赖，改用纯 HTTP 方式调用 AI 和 OCR API

## 📝 修改内容

### 1. 修改 pom.xml
**移除**：
```xml
<!-- 阿里云 OCR SDK（移除） -->
<dependency>
    <groupId>com.aliyun</groupId>
    <artifactId>ocr20210707</artifactId>
    <version>1.0.0</version>
</dependency>
```

**保留**（DashScope SDK 如果也下载不来就一起移除）：
```xml
<!-- 阿里云 DashScope SDK -->
<dependency>
    <groupId>com.alibaba</groupId>
    <artifactId>dashscope-sdk-java</artifactId>
    <version>2.15.0</version>
</dependency>
```

### 2. 修改 QwenAiClient.java
改用**RestTemplate**或**HttpURLConnection**直接调用 DeepSeek API：
- API 端点：`https://api.deepseek.com/chat/completions`
- 使用 HTTP POST 请求
- 不需要 SDK，只需要 API Key

### 3. 修改 OcrService.java
改用**百度 OCR API**（HTTP 方式）：
- API 端点：百度智能云 OCR
- 使用 HTTP POST 请求
- 先获取 access_token，再调用 OCR 接口

### 4. 修改配置类 AliyunConfig.java
改为通用的 AI 配置类，配置：
- DeepSeek API Key
- 百度 OCR API Key 和 Secret

### 5. 修改 application.yml
配置新的 API 信息：
```yaml
ai:
  deepseek:
    api-key: ${DEEPSEEK_API_KEY}
    base-url: https://api.deepseek.com
  baidu-ocr:
    api-key: ${BAIDU_API_KEY}
    secret-key: ${BAIDU_SECRET_KEY}
```
