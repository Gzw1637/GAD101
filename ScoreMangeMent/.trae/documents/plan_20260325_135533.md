# 修复分数段分布不合理问题

## 🐛 问题分析

当前代码使用固定的分数段分布（100 分制）：
- 90 分以上、80-89 分、70-79 分、60-69 分、60 分以下

但不同科目满分不同：
- **语文、数学、英语**：满分 150 分
  - 优秀：≥120 分（80%）
  - 良好：≥105 分（70%）
  - 及格：≥90 分（60%）
- **物理、化学、生物、政治、历史、地理**：满分 100 分
  - 优秀：≥80 分（80%）
  - 良好：≥70 分（70%）
  - 及格：≥60 分（60%）

## 📝 修复方案

### 1. 修改 `calculateStatistics` 方法
添加科目类型参数，根据科目自动调整分数段：

```java
private Map<String, Object> calculateStatistics(List<ScoreVO> scores, Integer subjectType) {
    // 判断满分值
    int fullScore = isFullScore150(subjectType) ? 150 : 100;
    
    // 计算及格线和优秀线
    double passLine = fullScore * 0.6;    // 60%
    double excellentLine = fullScore * 0.8; // 80%
    
    // 动态生成分数段
    Map<String, Integer> distribution = new LinkedHashMap<>();
    if (fullScore == 150) {
        distribution.put("120 分以上", count(scores, 120, null));
        distribution.put("105-119 分", count(scores, 105, 119));
        distribution.put("90-104 分", count(scores, 90, 104));
        distribution.put("75-89 分", count(scores, 75, 89));
        distribution.put("75 分以下", count(scores, null, 75));
    } else {
        distribution.put("90 分以上", count(scores, 90, null));
        distribution.put("80-89 分", count(scores, 80, 89));
        distribution.put("70-79 分", count(scores, 70, 79));
        distribution.put("60-69 分", count(scores, 60, 69));
        distribution.put("60 分以下", count(scores, null, 59));
    }
    
    // 计算及格率和优秀率
    long passCount = count(scores, passLine, null);
    long excellentCount = count(scores, excellentLine, null);
}
```

### 2. 修改调用处
传递科目类型参数：
```java
Map<String, Object> stats = calculateStatistics(scores, exam.getSubjectType());
```

### 3. 修改 AI 分析 Prompt
在调用 AI 时，告知满分值和评分标准。
