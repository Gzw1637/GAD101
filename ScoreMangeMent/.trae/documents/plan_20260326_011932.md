### 2. 新增后端接口

#### 接口 1：根据考试名称和科目查询考试

```java
@GetMapping("/search")
public Result<List<ExamVO>> searchExams(

```

#### 接口 2：根据用户名搜索学生
```java
// StudentController.java
@GetMapping("/search-by-username")
public Result<StudentVO> searchByUsername(@RequestParam("username") String username)
```

### 3. 前端逻辑实现

```javascript
// 搜索学生（自动补全）
const searchStudent = async (queryString, cb) => {
  if (!queryString) {
    cb([])
    return
  }
  
  try {
    const res = await request.get('/api/student/search-by-username', {
      params: { username: queryString }
    })
    if (res.code === 200 && res.data) {
      cb([{
        value: res.data.username,
        studentId: res.data.studentId,
        name: res.data.name
      }])
    } else {
      cb([])
    }
  } catch (error) {
    cb([])
  }
}

// 选择学生
const handleStudentSelect = (item) => {
  uploadForm.value.studentId = item.studentId
  uploadForm.value.studentName = item.name
}

// 提交分析
const handleUpload = async () => {
  // 先根据考试名称和科目查询考试 ID
  const examRes = await request.get('/api/exam/search', {
    params: {
      examName: uploadForm.value.examName,
      subjectType: uploadForm.value.subjectType
    }
  })
  
  if (examRes.data && examRes.data.length > 0) {
    uploadForm.value.examId = examRes.data[0].examId
    // 然后上传图片...
  }
}
```

### 4. 新增 Mapper 查询方法

```java
// ExamMapper.java
List<ExamVO> searchByExamNameAndSubject(
    @Param("examName") String examName,
    @Param("subjectType") Integer subjectType
);

// StudentMapper.java
StudentVO searchByUsername(@Param("username") String username);
```

### 5. SQL 查询

```xml
<!-- ExamMapper.xml -->
<select id="searchByExamNameAndSubject" resultType="ExamVO">
    SELECT * FROM g_exam
    WHERE exam_name LIKE CONCAT('%', #{examName}, '%')
    AND subject_type = #{subjectType}
    ORDER BY create_time DESC
</select>

<!-- StudentMapper.xml -->
<select id="searchByUsername" resultType="StudentVO">
    SELECT * FROM zw_student
    WHERE student_code = #{username}
    LIMIT 1
</select>
```
