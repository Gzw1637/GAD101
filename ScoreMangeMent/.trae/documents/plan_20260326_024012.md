## 📋 修改计划

### 需求分析
1. 移除自动补全的下拉建议列表
2. 用户输入学号后自动查询（失去焦点或按回车时）
3. 查询到学生后，姓名字段保持锁定状态
4. 状态标签改为"验证成功"（绿色）

### 修改文件

**PaperUpload.vue**

### 具体修改

1. **移除 el-autocomplete 的下拉显示**
   - 将 `el-autocomplete` 改为普通 `el-input`
   - 添加 `@blur` 事件（失去焦点时查询）
   - 添加 `@keyup.enter` 事件（按回车时查询）

2. **修改查询逻辑**
   - 不再使用 `fetch-suggestions`
   - 改为直接调用 API 查询学生
   - 查询成功后显示姓名，但字段保持禁用

3. **修改状态显示**
   - 将"已解锁"改为"验证成功"
   - 状态标签类型改为 `success`
   - 图标改为 `circle-check`

4. **修改变量名**
   - `studentNameUnlocked` → `studentVerified`
   - 语义更准确

### UI 交互流程

```
1. 用户输入学号 → 2026010001
2. 按回车或失去焦点
3. 自动调用 API 查询
4. 查询成功：
   - 姓名字段显示姓名（保持禁用 🔒）
   - 状态标签：✅ 验证成功
   - 提示消息：找到学生 xxx
5. 查询失败：
   - 姓名字段清空
   - 状态标签：❌ 未找到
   - 提示消息：未找到该学生
```
