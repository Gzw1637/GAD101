## 📋 修改计划

### 问题分析

1. **分数识别错误**（144 分→45 分）
   - 原因：AI 提示词没有告知满分值
   - AI 可能把 150 分制的试卷按 100 分制评估

2. **输出包含英文**
   - 原因：前端直接显示 JSON 原始内容
   - JSON 字段名是英文的（score, strengths, weaknesses 等）

3. **OCR 识别可能不准确**
   - 需要优化 OCR 识别逻辑

### 修改方案

#### 1. 修改 QwenAiClient.java - 优化 AI 提示词

**analyzeStudentPaper 方法**：
- 添加满分值参数（subjectType）
- 在提示词中明确告知 AI 这是 150 分制还是 100 分制
- 要求 AI 返回中文评语，不要 JSON 格式

#### 2. 修改 AiAnalysisServiceImpl.java - 传递科目信息

**uploadAndAnalyzePaper 方法**：
- 传递 subjectType 给 AI 分析

**analyzeStudentPaper 方法**：
- 传递 subjectType 给 AI 分析

#### 3. 修改前端 PaperUpload.vue - 美化显示

- 解析 AI 返回的 JSON
- 显示为中文格式化的报告
- 隐藏原始 JSON

### 具体改动

**QwenAiClient.java**：
```java
public String analyzeStudentPaper(String studentName, String subjectName, 
                                  Integer subjectType, String ocrContent) {
    // 判断满分值
    int fullScore = isFullScore150(subjectType) ? 150 : 100;
    
    // 提示词中添加：
    prompt.append("本试卷满分为").append(fullScore).append("分\n");
    prompt.append("请根据 150 分制/100 分制 标准进行评分\n");
    prompt.append("要求：返回中文分析报告，不要 JSON 格式\n");
}
```
