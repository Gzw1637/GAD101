## 修复计划

### 问题分析
- 前端调用 `/api/score/my` 接口返回 404
- 后端缺少该接口，没有根据 studentID 筛选成绩的功能

### 需要完成的任务

1. **更新 ScoreVO 实体类**
   - 添加 `examTime` 字段（考试时间）
   - 添加 `remark` 字段（备注信息）
   - 添加对应的 getter/setter 方法

2. **创建 Mapper 方法**
   - 在 ScoreMapper 中添加根据学生 ID 查询成绩的方法
   - 在 ScoreMapper.xml 中编写关联查询 SQL（JOIN exam 表获取考试时间和备注）

3. **创建 Service 方法**
   - 在 ScoreService 中添加查询学生成绩的业务逻辑
   - 支持按 examId 和 subjectType 筛选

4. **创建 Controller 接口**
   - 在 ScoreController 中添加 `/api/score/my` 接口
   - 从登录信息中获取当前学生 ID
   - 返回包含考试时间和备注的成绩列表

### 技术要点
- 使用 MyBatis 编写灵活的关联查询 SQL
- 遵循 Vue3 + Vite 官方脚手架结构
- 按照用户规则，实体类手写 getter/setter，不使用 Lombok
