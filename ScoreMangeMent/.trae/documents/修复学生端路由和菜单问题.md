# 修复学生端路由和页面问题

## 问题原因
1. 菜单 index 使用了相对路径而不是绝对路径
2. 路由嵌套配置不正确
3. Layout 组件需要启用 router 模式

## 解决方案

### 1. 修复 Student.vue 菜单路径
- 将 `index="student/score"` 改为 `index="/student/score"`
- 其他菜单项也需要修正

### 2. 修复路由配置
- 保持现有配置，应该问题不大
- 确保 Student 组件使用 RouterView 显示子路由

### 3. 确保 Layout 组件启用了 router 模式
- 检查 Layout.vue 是否有 router 属性

## 修改文件
1. Student.vue - 修正菜单 index 路径
2. 如需要，修复路由配置
