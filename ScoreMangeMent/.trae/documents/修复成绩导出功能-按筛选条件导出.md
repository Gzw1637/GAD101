## 问题分析
前端导出成绩时，**没有使用当前的筛选条件**，而是重新调用 `/api/score/list` 获取所有数据，导致导出的数据与页面显示的不一致。

### 具体原因
1. 前端 `handleExport` 函数中，调用 `request.get('/api/score/list')` 时**没有传递筛选参数**
2. 后端导出接口期望接收 `List<ScoreVO>`，但前端应该传递筛选条件而非完整数据列表
3. 对比教师导出功能，成绩导出接口也需要改为接收查询参数

## 解决方案
修改后端 `ScoreController` 的导出接口，改为接收查询参数（`@RequestParam`），并根据条件查询后导出。

### 具体修改
1. **修改后端** `ScoreController.java` 的 `/api/score/export` 接口：
   - 将 `@RequestBody List<ScoreVO>` 改为多个 `@RequestParam` 参数
   - 调用 `scoreService.getScoresByFilters()` 方法获取筛选后的数据
   - 如果没有筛选条件，则导出所有成绩

### 修改后的接口签名
```java
@PostMapping("/export")
public void exportScores(
    HttpServletRequest request,
    @RequestParam(required = false) Integer subjectType,
    @RequestParam(required = false) String examName,
    HttpServletResponse response)
```

### 前端修改
修改 `handleExport` 函数，传递筛选参数而非完整数据列表：
```javascript
const params = {}
if (filterExamName.value) params.examName = filterExamName.value
if (filterSubjectType.value) params.subjectType = filterSubjectType.value

const response = await request.post('/api/score/export', null, {
  params,
  responseType: 'blob'
})
```
