## 问题分析
在批量导入教师功能中，当向用户表插入数据时，用户身份值被错误地设置为14981001（学生身份），而正确的教师身份值应该是14981002。

## 问题定位
问题出现在 `ScoreBackend/src/main/resources/mapper/TeacherMapper.xml` 文件的 `insertUser` 方法中，SQL语句硬编码了错误的角色值：

```xml
<insert id="insertUser" parameterType="org.gzw.backend.entity.Teacher">
    INSERT INTO g_user (USER_ID, USER_NAME, PASSWORD, NAME, USER_STATUS, ROLE, LOGIN_FAIL_COUNT, LOCK_TIME)
    VALUES (#{userId}, #{userName}, #{password}, #{name}, 10001001, 14981001, 0, null)
</insert>
```

## 解决方案
修改 `TeacherMapper.xml` 文件中的 `insertUser` 方法，将 ROLE 字段的值从 14981001 改为 14981002，确保导入的教师用户具有正确的教师身份。

## 具体修改步骤
1. 打开 `ScoreBackend/src/main/resources/mapper/TeacherMapper.xml` 文件
2. 定位到 `insertUser` 方法的 SQL 语句
3. 将 `ROLE` 字段的值从 `14981001` 修改为 `14981002`
4. 保存文件

## 验证方法
修改完成后，重新执行批量导入教师操作，检查导入的教师用户在用户表中的身份值是否正确设置为14981002。
