## 📋 重构方案

### 核心改动

**1. 新建考试列表页面** (`ExamListView.vue`)
- 显示所有考试记录（表格形式）
- 列包括：考试名称、科目、考试时间、操作
- 每行右侧有"试卷分析"按钮
- 点击按钮跳转到识图页面，并传递考试 ID 和科目参数

**2. 修改识图页面** (`PaperUpload.vue`)
- 支持从 URL 参数接收 `examId` 和 `subjectType`
- 自动带出考试名称和科目（只读显示）
- 学生姓名字段初始为锁定状态 🔒
- 输入学号后自动解锁并显示姓名 ✅
- 然后上传图片进行分析

**3. 修改路由配置** (`router/index.js`)
- 新增 `/teacher/exam-list` 路由指向新页面
- 修改 `/teacher/paper-upload` 支持 URL 参数

**4. 修改菜单配置** (`Teacher.vue`)
- 将"AI 成绩分析"菜单改为"考试列表"
- 原 AI 分析功能整合到考试列表的操作按钮中

### 文件修改清单

**新增文件：**
- `ScoreFrontend/src/views/ExamListView.vue` - 考试列表页面

**修改文件：**
- `ScoreFrontend/src/views/PaperUpload.vue` - 识图页面（支持参数传递 + 锁定姓名）
- `ScoreFrontend/src/views/Teacher.vue` - 菜单配置
- `ScoreFrontend/src/router/index.js` - 路由配置

### 用户体验流程

1. 用户进入"考试列表"页面
2. 查看当前所有考试及科目
3. 点击某条记录的"试卷分析"按钮
4. 自动跳转到识图页面，考试信息已填充
5. 输入学生学号 → 自动显示姓名（解锁）
6. 上传试卷图片
7. 点击"上传并分析"

### 优势

✅ 更直观的考试选择方式  
✅ 避免用户手动搜索考试  
✅ 姓名字段锁定增强安全性  
✅ 流程更清晰，减少误操作
